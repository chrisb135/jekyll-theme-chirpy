## Antes da aula: Finalmente, dual boot

Como foi acordado na aula anterior, fui atrás do Nelson para me ajudar com meu dual boot. Porém, mesmo com o prórprio tendo uma imagem do ubuntu pronta para instalação, o processo não foi tão símples.

Um erro persistente referente a fragmentação de disco foi o maior obstáculo para a instalação. Depois de muitas tentativas, foi necessário uma reparação completa do disco dentro do próprio Windows para finalmente possibilitar a instalação do dual boot, que acabou me fazendo me atrasar alguns minutos para a aula.

## Tutorial 1

O primeiro bloqueio que eu encontrei foi a minha própria inexperiência com o Linux. Uma das primeiras coisas que fiz foi tentar executar um comando pacman no Ubuntu e, após a falha desse comando, rodar o comando `sudo apt install pacman`, que resultou na instalação de uma versão um tanto quanto secundária do jogo Pac-man. 

Depois de ser devidamente ridicularizado por essa tentativa, o restante do tutorial prosseguiu sem grandes problemas exceto pela conexão de internet dentro do laboratório dificultar o download da imagem que seria utilizada para configurar a máquina virtual dos próximos tutoriais, bem como alguns erros de digitação na confecção do script "todos-em-um", provocados pela minha insistência em escrever o script a mão ao invés de simplesmente copiá-lo do tutorial e colá-lo no meu arquivo.
